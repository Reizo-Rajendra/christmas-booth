Sebuah website interaktif bertema **Artisanal Vintage Christmas & 3-Cut Photobooth Studio** yang terinspirasi dari tren viral photobooth Korea (*인생네컷 / Life 3-Cuts*) dan estetika kerajinan tangan retro. Diciptakan dengan dedikasi tinggi oleh **Reizo Rajendra Dianta** untuk semua teman, keluarga, dan pengunjung dalam merayakan kehangatan Natal 2026 dan menyambut Tahun Baru 2027.

## ✨ Fitur-Fitur Utama

### 1. 💌 3D Wax-Sealed Red Velvet Envelope (Hero Intro)
- **Amplop Merah Beludru 3D**: Tertutup rata (*100% flush*) dengan segel lilin fisik berstempel ornamen pohon Natal emas.
- **Suara Retak Lilin Fisik (*Physical Wax Crack Audio*)**: Segel lilin pecah disertai partikel retakan dan efek suara realistis saat diklik.
- **Kartu Pos Meluncur Naik**: Kartu pos vintage terangkat keluar dari saku amplop secara tiga dimensi.
- **Pilihan Kejutan (*Surprise Prompt*)**:
  - Pilihan **"Yes, Open It"** memicu semburan konfeti, musik vokal Natal berputar, dan transisi mulus ke pengalaman studio utama.
  - Pilihan **"Not Yet"** memberikan respon manis yang bisa dibuka kapan saja.

### 2. 📸 Vintage 3-Cut Photobooth Studio (인생네컷)
- **Format Eksklusif 3 Foto (3-Cut Strip)**:
  - Tata letak vertikal strip 3 foto yang proporsional, rapi, dan estetis (bebas tampilan acak).
- **Live Webcam Mirroring & Multi-Camera Switcher**:
  - Live mirror video stream beresolusi tinggi langsung dari webcam laptop/PC.
  - Pendeteksi kamera ganda otomatis (*device switcher* jika tersedia webcam USB eksternal atau kamera virtual).
  - Terintegrasi *auto-listener* izin kamera Chrome (*langsung aktif begitu izin dialihkan ke "Allow"*).
- **Dukungan Kamera HP & Upload File**:
  - Tombol emas **`📸 Ambil Foto Kamera HP / Upload 3 Foto`** untuk langsung membuka kamera native ponsel atau galeri file.
- **Auto Capture Countdown**:
  - Hitungan mundur 3.. 2.. 1.. per foto dengan panduan pose (*Pose 1: Big Warm Smile*, *Pose 2: Peace / Heart Hands*, *Pose 3: Cute Holiday Wink*).
  - Dilengkapi kilatan blitz (*flash pop*) dan suara shutter kamera DSLR mekanik.
- **10 Tema Bingkai Foto Mewah (*Luxury Frame Themes*)**:
  1. *Royal Crimson Velvet & Gold*
  2. *Scottish Highland Tartan Plaid*
  3. *Alpine Pine & Evergreen Holly*
  4. *Snowflake Pastel Frost*
  5. *Gingerbread & Royal Icing*
  6. *Vintage 90s Kodak 35mm Film*
  7. *Silk Holiday Ribbon & Bows*
  8. *Midnight Constellation & Stars*
  9. *The Holiday Times Vintage Newsprint*
  10. *Seoul Minimalist Studio White*
- **5 Filter Sinematik**:
  - *Warm Hearth* (Semburat lilin hangat keemasan)
  - *Vintage Film* (Kodachrome tone retro)
  - *Holiday Glow* (Cahaya lembut berpendar)
  - *Winter Frost* (Sejuk salju kebiruan)
  - *Classic B&W* (Hitam-putih film noir)
- **Interactive Sticker Tray**:
  - Pasang stiker festive (topi Santa, tanduk rusa, mistletoe, pita merah, boneka jahe, bintang starlight). Stiker dapat digeser/diposisikan bebas pada strip.
- **Teks Footer Interaktif**:
  - Klik langsung teks *"MERRY CHRISTMAS 2026"* atau subjudul untuk mengganti catatan kenanganmu.
- **Ekspor Resolusi Tinggi (High-Res PNG)**:
  - Render Canvas resolusi tinggi siap cetak dengan watermark resmi: `Made by Reizo Rajendra Dianta`.
  - **Otomatis Tersimpan ke Database**: Setiap foto yang diunduh langsung tersimpan di database backend server.

### 3. 🎄 The Christmas Memory Tree (Interactive Photo Mosaic)
- **Pohon Natal Raksasa dari Foto Polaroid**:
  - 10 susunan foto polaroid bertingkat dihiasi untaian lampu *fairy lights* kelap-kelip dan bintang emas bercahaya di puncak.
- **10 Momen Asli Reizo Rajendra Dianta**:
  - Menampilkan 10 foto otentik Reizo sepanjang tahun 2026, berujung pada foto siluet matahari terbenam emas di pantai (*Golden Sunset Silhouette*) pada foto ke-10.
- **Interactive Polaroid Lightbox**:
  - Klik polaroid mana pun untuk melihat foto secara HD, membaca tanggal, dan membaca pesan kenangan.
- **Hang on Tree**:
  - Foto dari studio photobooth dapat langsung digantungkan ke pohon ini.

### 4. ♫ Peppermint Turntable Vinyl Music Player
- Piringan hitam berputar bertema permen peppermint dengan jarum *tonearm* interaktif.
- **Lagu Natal Vokal Asli**:
  1. *Last Christmas* — Wham! (Original Vocal)
  2. *All I Want for Christmas Is You* — Mariah Carey (Original Vocal)
  3. *White Christmas* — Frank Sinatra (Original Vocal)
  4. *Jingle Bells* — Frank Sinatra (Original Vocal)
- Mesin cadangan **Web Audio Synthesizer** murni (suara instrumen tetap berbunyi tanpa koneksi internet).

### 5. ⏳ Live Christmas Countdown & December Calendar
- Hitung mundur live waktu nyata (Hari, Jam, Menit, Detik) menuju puncak perayaan Natal 2026.
- Kalender Desember interaktif bernuansa vintage dengan penanda hari spesial.

### 6. 🎅 Mini-Game: "Find the Hidden Santa!"
- Ilustrasi desa musim dingin cat air (*watercolor winter village*) lengkap dengan rumah merah, pohon cemara, dan danau beku.
- Santa bersembunyi secara acak. Klik lokasi yang dicurigai untuk mendapatkan petunjuk arah hingga Santa melompat gembira disertai suara kemenangan dan konfeti!

### 7. 📖 Spiral Holiday Scrapbook & Universal Letter
- Buku harian spiral dengan ring logam keemasan dan kertas perkamen bertekstur.
- Surat ucapan hangat dari **Reizo Rajendra Dianta** untuk semua orang (*To: Everyone*) yang telah menjadi bagian berharga sepanjang tahun 2026.
- **Voucher Natal Interaktif (Holiday Coupons)**: Kupon pelukan hangat, cokelat panas, liburan keliling kota, dan permintaan Natal yang bisa di-redeem dengan efek suara dan konfeti.

### 8. 🛡️ Private Admin Dashboard (`/admin.html`)
- Dashboard privat khusus Reizo untuk melihat semua strip foto yang dibuat oleh pengunjung.
- Fitur:
  - Melihat galeri semua foto yang masuk secara aman tanpa mengganggu halaman utama.
  - Mengunduh file PNG resolusi tinggi asli kapan saja.
  - Menghapus foto testing/spam langsung dari database via tombol hapus 🗑️.

## 🛠️ Tech Stack

- **Frontend**:
  - Vanilla JavaScript (ES6+ Modular Architecture, Zero Bloatware)
  - HTML5 Canvas API (High-Resolution 300 DPI Photostrip Rendering)
  - CSS3 Modern (Custom Properties, 3D Transforms, Backdrop Blur, Responsive Grid)
  - Web Audio API (Synthesizer Chimes, Shutter Sounds, Vinyl Tone Effects)
  - Canvas Confetti Library
- **Backend & Database**:
  - Node.js Built-in HTTP Server (Lightweight, Zero external dependencies)
  - RESTful API (`GET /api/submissions`, `POST /api/submissions`, `DELETE /api/submissions/:id`)
  - File-based JSON Database (`data/photostrips.json`)
  - Base64 High-Res Image Storage (`uploads/photostrips/`)
  - Byte-Range Audio Streaming & Cache-Busting Headers (`no-cache, must-revalidate`)

## 🚀 Cara Menjalankan Proyek Secara Lokal

### Prasyarat
- [Node.js](https://nodejs.org/) versi 16 atau yang lebih baru.

### Langkah Menjalankan:

1. **Clone Repository:**
   ```bash
   git clone https://github.com/Reizo-Rajendra/christmas-booth.git
   cd christmas-booth
   ```

2. **Jalankan Server:**
   ```bash
   npm start
   # atau
   node server.js
   ```

3. **Buka di Browser:**
   - **Halaman Utama**: [http://localhost:3000](http://localhost:3000)
   - **Halaman Admin Database**: [http://localhost:3000/admin.html](http://localhost:3000/admin.html)

## 📸 Panduan Mengaktifkan Webcam di Chrome (Hanya 2 Langkah)

Jika webcam tidak langsung menyala di browser Chrome:
1. Klik ikon **`( i )`** atau **Gembok** di sebelah kiri tulisan `localhost:3000` pada address bar Chrome.
2. Pada baris **Camera (Kamera)**, ubah menjadi **Allow (Izinkan)**.
3. Web akan langsung otomatis mendeteksi dan menyalakan webcam tanpa perlu refresh!
4. Atau kamu juga bisa langsung klik tombol emas **`📸 Ambil Foto Kamera HP / Upload 3 Foto`** untuk memilih foto dari perangkat.
